# 随手记

随手记用于保存阅读中的摘录和想法，每条关联一篇个人库论文。它独立于 Markdown 个人笔记、浏览器高亮和 Agent 会话，不调用模型。

## 使用

- 主侧边栏的“随手记”汇总所有记录，可搜索内容或论文标题、筛选来源并分页浏览。
- 阅读器工具栏的“随手记”在右侧工作区展示当前论文的记录。
- 在 PDF 中选中文字，点击“记一条”直接保存。成功后可点击“查看”，不会自动切走 Agent 对话。
- 手动新增只需选择论文、填写内容；在阅读器内自动关联当前论文。
- 编辑遇到修订冲突会保留草稿，重新加载后可以对照最新内容再保存。

## 来源与存储

记录保存在现有个人 SQLite 的 `quick_notes` 表，包含内容、论文关联、来源快照、修订版本和时间。选区记录还保存 PDF SHA、物理页码及版本名称。创建请求按 `clientRequestId` 去重，同一文字的独立提交允许成为不同记录。

“返回原文”打开原 PDF 版本及选区的第一页，不使用其他 PDF 版本的同一页替代。原版本不存在时可通过来源论文标题打开个人库工作台。

删除来源论文后，记录和创建时的论文 ID、标题、作者、年份快照保留，显示“来源已删除”。重新导入同 ID 的论文不会自动重建已删除的关联。删除随手记不会修改论文或笔记文件。

## HTTP 接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/quick-notes?query=&paperId=&page=1&pageSize=30` | 返回 `notes`、`total`、分页参数及来源筛选项 `sources` |
| `GET /api/quick-notes/:id` | 读取单条最新记录，用于编辑冲突后的重新加载 |
| `POST /api/quick-notes` | 创建，参数为 `content`、`paperId`、`clientRequestId`，可选 `locator: { pdfSha256, pages }` |
| `PATCH /api/quick-notes/:id` | 编辑，参数为 `content`、`expectedRevision` |
| `DELETE /api/quick-notes/:id` | 删除记录 |

创建和编辑返回 `{ note }`，删除返回 `{ deleted: true }`。校验失败为 400，来源或记录不存在为 404，请求 ID 冲突或修订冲突为 409。列表每页最多 100 条；30 条是默认分页大小，不是保存上限。

这些接口用于网页直接操作，不注册为 Agent 工具，不经过 Agent 写入审批。
