| --- | --- |
| `apply_canvas_changes` | Request application of a saved proposal and wait for the user to select changes in the canvas research preview. Never self-approve, including in auto permission mode. Closing the panel does not apply changes; cancellation preserves the proposal. |
| `get_canvas_analysis` | List research checkpoints or read one paginated method-card matrix with source freshness, fixed paper list, evidence, gaps and next steps. |
| `get_canvas_nodes` | Read a page of in-scope nodes, incident relations and groups. Paper nodes explicitly distinguish saved canvas candidates from personal-library records. | `preview_canvas_changes` | Create a research proposal without modifying the canvas. add_node supports paper or analysis-backed text only; for authors, teams and ordinary text use propose_canvas_nodes. ## 网页会话 MCP 工具

项目 MCP 配置中启用的服务，在通用、论文阅读和画布会话启动时动态注册。工具名为 mcp__服务名__工具名，实际参数通过 inspect_agent_tools 查询。工具调用沿用网页权限确认，连接与配置说明见 [浏览器 MCP](browser-mcp.md)。
