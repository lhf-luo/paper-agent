# 关系画布研究

打开关系画布的“画布研究”面板，设置研究问题、比较维度与预算，再打开本画布的 Agent 会话。“保存并准备研究任务”将任务放入输入框，由用户发送。普通聊天不会自动执行整套综述流程。

研究面板包括目标、覆盖、方法矩阵、关系建议、补搜与变更预览。默认视野为整张画布，也可以按会话选择节点或 Agent 的直接邻居。论文按个人库实际 ID 去重，卡片自定义名称不会改变类型。同一画布的会话共享目标与分析记录，不自动读取其他会话的聊天记录。

## 阅读与继续

- 每份分析固定纳入节点和论文，后续新增论文显示为待纳入；新建分析可复用有效的方法卡。
- 默认每轮最多深入研究 12 篇新增论文。摘要初筛、方法取证、全文研究分别计数；未知字段保持未知。
- 方法卡记录正文或 PDF 证据。PDF 证据保存文件 SHA256 和物理页码，笔记证据保存笔记版本；证据按钮打开个人阅读工作台。
- 修改研究问题、材料版本或使用过的笔记会使相关结果需要复核。平移、缩放、节点位置和显示名称不触发论文重读。
- 中止、失败和服务重启保留检查点，重新研究时先查询已有分析；研究笔记与 Wiki 不自动创建。

## 补搜与编排

外部检索必须先保存计划并在面板接受。默认最多 4 个查询变体、4 次外部工具调用、每提供商 100 条，引用扩展为一层。计划限制查询、提供商、日期和预算。Search Run 保留候选、错误和截断信息；用户选择候选后走现有入库确认流程，再创建加入画布的预览。

arXiv 支持 UTC 首次提交日期；其他提供商沿用现有工具的年份过滤，精确截止日期仍需核验。限流、零结果、接口失败不能据此认定研究空白。

方法分类、技术演进、问题—方法—证据三种布局生成分组区域和文本总结卡。固定节点不参与自动移动。关系区分引用、采用、扩展、相似、互补和分歧；用户接受关系不提升其证据等级。

所有画布变更先预览，可选择部分建议，必要依赖自动带入。应用校验版本和来源，在同一 SQLite 事务内提交，重复请求不会重复创建。版本冲突保留草稿与提案。普通撤销按整批恢复，刷新后也可以从已应用记录撤销；对象已有后续编辑时报告冲突。

## 实现边界

`src/canvas` 提供共享应用逻辑，HTTP 接口和 7 个画布 Agent 工具复用该逻辑。会话工厂绑定 namespace、画布 ID 和会话 ID，通用与论文会话不注册这些工具。`canvasContext` 只传递当前 Agent 节点和选择，实际视野由服务端校验。

研究记录以 namespace、画布 ID、类型和记录 ID 存于 `canvas_research_records`，使用修订号检查并发写入。画布事件流通知检查点、计划、提案和画布版本变化。删除画布清理专属研究记录；复制画布只复制设置与已展示内容，生成内容标为待复核快照，不复制分析运行与待应用提案。

工作流定义见 `.agents/skills/canvas-research/SKILL.md`；取证与检索分别遵循现有 `paper-research`、`literature-corpus-manager` 契约。
