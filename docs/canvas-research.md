# 关系画布研究

打开关系画布的“画布研究”面板，设置研究问题、比较维度与预算，再打开本画布的 Agent 会话。“保存并准备研究任务”将任务放入输入框，由用户发送。普通聊天不会自动执行整套综述流程。

研究面板包括目标、覆盖、方法矩阵、关系建议与变更预览。默认视野为整张画布，也可以按会话选择节点或 Agent 的直接邻居。论文按个人库实际 ID 去重，卡片自定义名称不会改变类型。同一画布的会话共享目标与分析记录，不自动读取其他会话的聊天记录。

## 阅读与继续

- 每份分析固定纳入节点和论文，后续新增论文显示为待纳入；新建分析可复用有效的方法卡。
- 默认每轮最多深入研究 12 篇新增论文。摘要初筛、方法取证、全文研究分别计数；未知字段保持未知。
- 方法卡记录正文或 PDF 证据。PDF 证据保存文件 SHA256 和物理页码，笔记证据保存笔记版本；证据按钮打开个人阅读工作台。
- 修改研究问题、材料版本或使用过的笔记会使相关结果需要复核。平移、缩放、节点位置和显示名称不触发论文重读。
- 中止、失败和服务重启保留检查点，重新研究时先查询已有分析；研究笔记与 Wiki 不自动创建。

## 补搜与编排

用户明确要求关键词、引用或作者检索时，直接调用已有检索工具。引用及作者扩展随后调用 `show_search_run_graph` 展示结果；通用关键词检索默认保留普通结果，仅在明确要求时生成图谱，不要求先创建分析或确认单篇补搜计划。Agent 自主提出的补搜先在对话中说明范围、来源与预算，用户同意后执行。默认最多 4 次外部检索调用、每提供商 100 条，引用扩展一层。个人库种子查询由底层统一扩展工具处理；OpenAlex 空结果或失败不会跳过可用的 Semantic Scholar 来源。错误和截断情况保留在 Search Run。

arXiv 支持 UTC 首次提交日期；其他提供商沿用现有工具的年份过滤，精确截止日期仍需核验。限流、零结果、接口失败不能据此认定研究空白。

方法分类、技术演进、问题—方法—证据三种布局生成分组区域和文本总结卡。固定节点不参与自动移动。关系区分引用、采用、扩展、相似、互补和分歧；用户接受关系不提升其证据等级。

所有画布变更先预览，可选择部分建议，必要依赖自动带入。应用校验版本和来源，在同一 SQLite 事务内提交，重复请求不会重复创建。版本冲突保留草稿与提案。普通撤销按整批恢复，刷新后也可以从已应用记录撤销；对象已有后续编辑时报告冲突。

## 日常节点编辑

画布会话额外注入 `propose_canvas_nodes`，支持批量提出作者、团队、普通文本和已有个人库论文节点，以及本批新节点与当前范围内节点之间的连线。普通和论文阅读会话不提供此工具；不需要先设置研究目标或创建分析记录。

例如：“为这篇论文创建作者节点并连接到论文，机构和主页未知时留空。”Agent 先读取论文作者元数据和画布版本，再提交提案；用户在“画布研究 → 变更预览”选择后应用。即使会话使用自动权限模式，工具仍须等待该预览确认。

服务端生成持久节点 ID、默认尺寸和避开现有节点的位置。`nodes[].key` 为本批引用名，连线端点用 `{ "new_node": "作者key" }` 或 `{ "node_id": "现有节点ID" }`。`request_id` 用于重试去重；修改批次应使用新标识。同名作者仅提示可能重复，不自动合并身份。论文节点必须引用已入库论文，应用时重新检查其存在性。

节点编辑复用版本冲突、必要依赖、事务应用和撤销。研究目标、论文摘要或 PDF 的变化不会使普通编辑提案失效；画布版本变化仍需重新预览。作者和团队卡使用当前画布的数据结构；此工具不创建笔记或新的 Agent 会话。

## 实现边界

`src/canvas` 提供共享应用逻辑，HTTP 接口、7 个研究工具、1 个节点编辑工具与 1 个搜索图谱工具复用该逻辑。会话工厂绑定画布 ID 和会话 ID，通用与论文会话不注册这些工具。`canvasContext` 只传递当前 Agent 节点和选择，实际视野由服务端校验。

研究记录以 画布 ID、类型和记录 ID 存于 `canvas_research_records`，使用修订号检查并发写入。画布事件流通知检查点、图谱、提案和画布版本变化。删除画布清理专属研究记录；复制画布只复制设置与已展示内容，生成内容标为待复核快照，不复制分析运行与待应用提案。

工作流定义见 `.agents/skills/canvas-research/SKILL.md`；取证遵循 `paper-research`。画布会话的 Skill 列表、资源加载和快捷命令过滤 `literature-corpus-manager`，检索流程统一由 `canvas-research` 指导，底层搜索工具仍可用。

## Search Run 搜索图谱

画布左侧“图谱管理”浏览已有图谱，支持重命名、隐藏、打开，以及从搜索记录分页创建图谱。每个批次对应一份图谱，可作为 search_graph 节点添加到画布；节点 entityId 引用 Search Run，不引用个人库论文。点击节点打开图谱，返回画布保留原布局。未入库论文仅存在于搜索结果中，不创建单篇候选节点。隐藏列表条目或删除图谱节点保留搜索记录和坐标。搜索图谱沿用列表、圆点网络、按需摘要详情和主动确认入库；支持真实引用、文献耦合与共被引网络；打开时只使用已有数据。图谱管理提供“补全关系”“应用新布局”“恢复上次布局”，不自动检索或重排。详见 [搜索图谱](search-graphs.md)。

工具 `show_search_run_graph` 仅在画布扩展注册。输入 `search_run_id`，可选 `filter_result_id`；输出 `searchRunId`、`resultCount`、`displayedCount`、`matchedCount`、`seedCount`、`status` 和 `title`。不触发检索、个人库写入或画布内容版本变化。原候选节点提案工具与补搜确认面板已移除。新建关系画布论文节点必须使用个人库 ID；历史候选快照仍可读取与入库，不再新增。

个人 SQLite 的 `canvas_search_graphs` 以画布 ID 和 Search Run ID 保存名称、可见状态、筛选引用、坐标、视口和筛选状态。论文内容直接来自 Search Run；原批次被删除或筛选失效时明确报错。复制画布复制图谱引用与视图；删除画布仅清理自己的引用，不删除搜索结果或个人论文。

接口基址 `/api/canvases/:id/search-graphs`：GET 列表；POST `{searchRunId, filterResultId?}` 打开；GET `/:runId` 读取轻量图谱；GET `/:runId/papers/:paperId` 读取详情；PATCH `/:runId/state` 保存带修订号的视图；POST `/:runId/open` 打开已有图谱且保留筛选；PATCH `/:runId` 修改名称；POST `/:runId/close` 从管理列表隐藏。事件沿用画布 research SSE。入库复用 `/api/library/import/prepare` 和 `/api/library/import/execute` 的确认流程。
