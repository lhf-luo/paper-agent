# PDF asset release set

This directory contains redistribution-safe metadata and manual annotations for the PDF asset detector. PDF files, rendered pages, debug images, and bootstrap candidate workspaces are local-only and ignored by Git. Commit the source manifest, reviewed gold annotations, and release baseline; regenerate candidate workspaces with `npm run eval:pdf-assets:bootstrap` when they are needed for review. Release annotations must explicitly declare `annotationStatus: "human-reviewed"`; detector-generated bootstrap candidates are rejected by the release script so they cannot accidentally score the detector against its own output.

The release set covers 59 fully inspected pages and 104 assets from 20 public arXiv papers in software security, reverse engineering, and AI. It retains the original NEUZZ, SAFE, Gemini, Software Security Patch Management, Attention Is All You Need, BERT, and AlphaCode papers and adds Dropout, Chain-of-Thought, CLIP, Denoising Diffusion, Deep Q-Networks, GPT-3, Graph Attention Networks, Mask R-CNN, Retrieval-Augmented Generation, ResNet, U-Net, Vision Transformer, and YOLO. Schema v2 fixes the expected PDF SHA-256 and lists `annotatedPages`; caption false positives are scored only on pages that were completely inspected. Regions use PDF points, a top-left origin, and include the visual object plus its caption. `continuationRegions` records later physical pages of a continued table.

Run `npm run eval:pdf-assets:fetch` to download the pinned arXiv PDFs into the ignored `eval-data/pdfs` directory and verify every SHA-256. Do not replace a PDF with another arXiv version without updating and manually reviewing its annotation.

The set intentionally includes hard layouts: two-column and single-column papers, narrow column figures, full-width figures, multiple assets on one page, two/six-panel figures, adjacent captions, long captions, pipe-separated captions, raster-only captions, captions above and below tables, algorithms, and a three-page table whose continuation pages repeat headers without repeating the caption. Four manually reviewed multi-panel figures now contribute 12 independently scored subfigure boxes. The release baseline pins required layout tags and emits a machine-readable coverage inventory. Rotated pages, scanned/OCR-only papers, non-English papers, publisher-rendered versions, unusually complex cross-column floating objects, and continued tables without repeated headers are recorded in `knownGaps`; they remain explicit expansion targets rather than implied measured capabilities.

Run `npm run eval:pdf-assets:check` as the release gate. It fails unless the release set retains at least 20 papers, 59 inspected pages, 104 gold assets, and 12 gold subfigures; caption precision/recall are at least 0.95; mean crop IoU is at least 0.75; P10 crop IoU is at least 0.50; every matched crop reaches IoU 0.50; mention and continuation precision/recall are at least 0.95; mean continuation crop IoU is at least 0.75; subfigure precision/recall are at least 0.95; and mean subfigure crop IoU is at least 0.55. The checked baseline is caption precision/recall 1.0/1.0, mean crop IoU 0.929572, P10 0.773381, mention precision/recall 0.991453/0.974790, continuation precision/recall 1.0/1.0, and subfigure precision/recall/mean IoU 1.0/1.0/0.648567. These metrics apply only to this fixed release set.

Artifact-link discovery has a separate 30-paper target set under `artifacts/`. Its machine-generated candidate snapshots are not gold. Use the Web **Quality evaluation** workflow described in [the Artifact evaluation guide](../docs/artifact-evaluation.md); the strict Artifact gate remains intentionally unavailable until real reviewers complete the set.
